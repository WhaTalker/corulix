# Independent Implementation and Source Admission

Corulix source is developed from authorized engineering inputs such as public
specifications, official upstream APIs, official language grammar definitions,
project requirements, and independently designed tests.

## Source-admission rule

Implementation material must have a documented right and reason to be included.
The project does not admit unlicensed copied source, tests, fixtures, patches,
queries, or internal implementation material from unrelated third-party
projects.

Public APIs, standards, specifications, documented behavior, and upstream
libraries may be used according to their licenses and the project's dependency
policy.

## Review expectation

When provenance is uncertain, the material is excluded until its origin and
license can be established. Provenance review is independent of whether the
candidate code appears technically compatible.
