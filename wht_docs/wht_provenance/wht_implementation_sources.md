# Authorized Implementation Sources

Corulix engineering may use the following implementation inputs:

1. WhaTalker product and architecture requirements.
2. Public Model Context Protocol specifications.
3. Official Model Context Protocol SDK documentation and APIs.
4. Official Tree-sitter runtime documentation and APIs.
5. Official Tree-sitter language grammar definitions admitted by dependency
   policy.
6. Official Rust documentation and standard-library APIs.
7. Public programming-language specifications.
8. Independently designed tests, fixtures, and queries.

Any additional source input must have clear provenance, a compatible license,
and an approved reason for inclusion before it is incorporated.
